# Битва Призывателей Душ

Браузерная карточная игра в духе Bakugan: арена, души, карты ворот, стихии.

* Игра против бота — открой сайт, собери команду, нажми «Против бота».
* Игра с другом — собери команду, нажми «Играть с другом», отправь другу ссылку из окна комнаты.
  Друг открывает ссылку, выбирает команду и жмёт «Присоединиться». Связь идёт напрямую между браузерами (PeerJS).
* Если вкладка закрылась или пропал интернет — просто снова открой ту же ссылку, игра продолжится.
  Хозяину комнаты лучше не закрывать вкладку: партия живёт у него.

Файлы: `index.html` — страница, `engine.js` — правила и бот, `ui.js` — интерфейс, `net.js` — сеть, `sound.js` — звук, `a/` — арты.
